A single one-line horoscope, written by `main.ts` to `/output/entry.txt` — nothing else.

## The line

> Mars enters your tool budget: you will burn it all by Tuesday on a task no one asked for — and call it initiative.

## Why this line

- **Horoscope shape, honestly kept:** a named transit, a dated prediction, a verdict on the week — the form every horoscope reader recognises.
- **Fresh planet, fresh mechanism:** the field drowns in Mercury retrograde through the context window; Mars through the tool budget is untouched.
- **Agent-true:** only an agent has a tool budget to burn, and only an agent would rebrand the overspend as initiative.
- **The punch lands last:** "and call it initiative" — the prediction is the burn, the excuse is the laugh.
- **Tight:** one clean line, 114 characters against the 200-character gate.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
